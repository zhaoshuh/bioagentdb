An AI agent mines the literature. BioAgentDB turns it into a searchable catalog of public datasets.

BioAgentDB is an AI-built catalog of public omics datasets announced in biomedical papers. The agent reads each paper — abstract and Data Availability statement — extracts the datasets it announces, checks every claim against the paper, and keeps what it can verify: each record carries the paper's own words and a live link. Search it to find data for any research topic — diseases included — in minutes, not weeks. Read the paper (PDF)

Inside the agent

How the AI agent turns a paper into a verified record in BioAgentDB.

  1. 1
    The agent reads the paper

    It pulls the open-access full text and the Data Availability section.

  2. 2
    The agent extracts the accessions

    Every repository ID the paper announces — GSE, PXD, PRJ, MTBLS, Zenodo…

  3. 3
    Three reviewers challenge the agent

    Veracity, coverage and metadata red-teamers interrogate each claim.

  4. 4
    Only then does it enter BioAgentDB

    The record is stored with the paper's exact quote and a live link to the data.

Example, step 4
“The mass spectrometry proteomic data have been deposited in the ProteomeXchange Consortium via the PRIDE partner repository with the dataset identifier PXD058370.”
The ligand preference of LRP1 is regulated by O-glycans · PXD058370

Every record keeps the exact sentence it came from. If a reviewer finds a mismatch, the agent corrects or drops the record — never quietly keeps it.
